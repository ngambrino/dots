# dots

My dotfiles & other config stuff.


## Prerequisites

1. [Install Homebrew](https://brew.sh) (will also install Xcode command line tools)
2. [Set up SSH connection to Github](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)


## Installation

* `git clone git@github.com:ngambrino/dots.git && cd dots`
* `brew bundle --no-lock --no-upgrade`
* `./setup`
